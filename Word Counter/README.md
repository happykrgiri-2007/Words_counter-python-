
# Word Counter Using Python

## About the Project
A simple Python-based Word Counter that reads
a text file and calculates the total number
of words present in it.



## Features
- Read text files
- Count total words
- Count total characters
- Count total lines
- Handle file not found errors
- Handle permission errors

## Technologies Used
- Python
- Regular Expressions
- File Handling
- Exception Handling

## How to Run

1. Run the following command:

  python word_counter.py

2. Enter the text file name.
3. View the counting results.
